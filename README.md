# SLUDGE TIDE — "What Rots, What Stays"

A ~9-minute 2D anime short, animated in **Blender 4.2 Grease Pencil**.

## What's in the box

| File | What |
|---|---|
| `Sludge_Tide.blend` | The Blender project: one scene per shot (72 shots, named by shot id, e.g. `n9_fall`) plus the **FILM** scene (Video Sequencer edit of every shot, the sound and the subtitles) |
| `output/sludge_tide.mp4` | The finished film: 1920x1080, 24 fps, H.264 + AAC |
| `output/sludge_tide.srt` | Subtitles (the film also has them burned in, from the FILM edit's text strips) |
| `build/sheets/cast.png` | Cast line-up rendered from the puppets |

## Working in Blender

Open `Sludge_Tide.blend` in Blender 4.2 (`~/tools/blender-4.2.23-windows-x64/blender.exe`).

* **Shots**: switch scenes with the scene selector (top right). Each shot has its own camera, sets and characters.
* **Characters** are cutout puppets: an Empty (`<shot>.<name>`, e.g. `n2_hall.iggy`) with one Grease Pencil object per body part,
  parented hip -> chest -> head / arms, hips -> legs. Rotate parts in Object mode; keys are stepped (constant) on twos,
  like TV anime. Drawings are shared across shots, so redrawing a part in Draw mode updates it everywhere.
* **Faces & hands**: eyes, brows, mouth and hands are drawing libraries on their own layers. The visible drawing is
  picked by a **Time Offset** modifier (`swap_eyes`, `swap_mouth`, `swap_hand`...) whose *Frame* is keyed — that is
  how the lip-sync works. Costume layers (Junk's teal streak, helmet, bandage, cracked goggles; Rust's crown, tears and
  Iggy's face) are toggled with keyed **Opacity** modifiers (`show_*`).
* **Effects** (speed lines, impact frames, rot webs, sludge clouds, splashes, rain, the scrap tornado, banners) are
  frame-by-frame Grease Pencil drawings; screen-space effects are parented to the camera. Glow is the Grease Pencil
  *Glow* shader effect + the compositor's Fog Glow.
* **FILM** scene: Video Sequencer edit. Picture strips are the rendered frames of each shot; dissolves are keyed
  strip opacity, dips are colour strips. Sound: the final mix (`MIX`) plus muted stems (music, sfx, beds, each voice line)
  you can unmute and rebalance. Subtitles are text strips (channel 8).

## Rebuilding

The project is generated by the build scripts in `blender/` (they drive Blender's own Grease Pencil API), so the
timing always matches the recorded voices:

```
set B=%USERPROFILE%\tools\blender-4.2.23-windows-x64\blender.exe
.venv\Scripts\python audio\tts.py           # character voices (local Kokoro model)  -> build/vo
.venv\Scripts\python audio\music.py         # score                                   -> build/audio/music.wav
.venv\Scripts\python audio\sfx.py           # effects + ambience                      -> build/audio/sfx.wav, beds.wav
.venv\Scripts\python audio\mix.py           # final mix (-16 LUFS) + srt
%B% -b --factory-startup --python blender\build.py                       # -> Sludge_Tide.blend
%B% -b Sludge_Tide.blend --python blender\render_shots.py -- --part 0/3   # (run 0/3, 1/3, 2/3 in parallel) -> build/frames
%B% -b Sludge_Tide.blend --python blender\finish.py                       # edit + final movie -> output/sludge_tide.mp4
```

Preview a few shots: `%B% -b --factory-startup --python blender\build.py -- --shots n9_fall,b7_fall --stills --nosave`
(writes `build/stills/`). `python tools\tile.py out.jpg build\stills\*.png` tiles them for review.

## Where things live

| To change | Edit |
|---|---|
| Dialogue, shot order, minimum shot lengths, transitions, action cues | `config/script.py` (then `audio\tts.py`, rebuild) |
| Character designs | `blender/bl/cast/junk.py`, `rust.py` (Iggy + Baron Rust), `others.py` (Granny, Sela, Magnus, Bolt, Pip, guards, Rustmites) |
| Sets (Gloamworks, Tumble Island, Graveyard Shelf, noodle boat, Stilts, cliff, Rattlecrown...) | `blender/bl/sets.py` |
| Effects animation | `blender/bl/fx.py` |
| A shot's staging, acting and camera | `blender/shots/ch1_night.py` ... `ch8_end.py` (one function per shot) |
| Voices | `audio/tts.py` (`VOICES`) |
| Score (Junk's clanky brass theme, Rust's cello + clock) | `audio/music.py` (`build()` is the cue sheet) |
